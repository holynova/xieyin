# 古籍典籍谐音梗追踪器 (Codex Resets)

基于 Sticker-Sheet Neo-Brutalism 设计系统的古籍典籍谐音梗挖掘与离线展示系统。严守不跨标点断句与全音节完全对齐法则，结合《CC-CEDICT 官方权威汉语大词典》挖掘爆笑典籍梗。
